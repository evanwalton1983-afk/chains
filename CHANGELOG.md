# Changelog

Newest first. One dated line per change. The version is the one shown in the app under Settings (gear icon, top right).

- 2026-10-23, v2.5.0: Alt line ladder in the prop sheet. New altLines module fits one distribution per prop to the no-vig main line (Poisson or negative binomial for counts, normal for passing yards, gamma for rushing, receiving and rush plus rec yards), blends its spread from the player's last 20 games and a per stat default at n / (n + 16), then prices every alternate rung from it, using the fairPrice module for the de-vig. The new Alt line ladder block shows fair odds, best price at your books and EV per rung for the side shown, and flags rungs at your EV bar (never under 3% or over 97%). The slider now also shows the model price for the line it is on, and a box takes the price your book shows for that line. Gamma replaces the log-normal asked for, and the blended spread replaces a hard cutoff, because both scored better on nflverse 2022 to 2024 games. No new pulls, credits or saved fields. Unit tests in tests/altlines.test.mjs.
- 2026-10-14, v2.4.0: Fair prices four ways. New fairPrice module removes the vig by multiplicative (the old method), additive, power and Shin, ported from the MIT licensed shin and penaltyblog packages with their notices. New Settings > Fair prices: Fair price method for the fair price shown (default Shin) and EV gate for every estimate, expected value, stake, clears-the-bar call and Better number flag (default Worst case, the lowest of the four for the side being bet). The method now shows next to each fair price. Closing values and the consensus stored on picks stay multiplicative so the Record stays on one scale. Unit tests in tests/, run with node --test.
- 2026-10-14, v2.3.0: Added CLAUDE.md with house rules for future changes. No app files changed, so the version stays at 2.3.0. Earlier changes were not logged here.
